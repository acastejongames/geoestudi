# Geoestudi

Aplicació web d'estudi en català per preparar la unitat **UP1: Geografia física — relleu, aigua i clima**.

## Contingut

- Composició de la Terra
- Formació del relleu i agents interns i externs
- Aigua al món
- Conceptes bàsics i accidents geogràfics
- Relleu d'Àfrica, Amèrica, Àsia, Oceania, Europa, Espanya i les Illes Balears

Inclou fitxes de memòria activa, preguntes tipus test, repàs de parelles, llista per preparar l'atles i seguiment local del progrés. No necessita compilació ni dependències: index.html és l'aplicació completa.

## Publicar amb GitHub Pages

A **Settings → Pages**, tria **Deploy from a branch**, selecciona `main` i la carpeta `/ (root)`. GitHub Pages publicarà el lloc a `https://acastejongames.github.io/geoestudi/` quan el desplegament acabi.
